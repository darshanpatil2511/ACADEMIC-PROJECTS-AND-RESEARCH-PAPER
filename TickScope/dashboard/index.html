Matching engine: v1 vs v2

v1 uses std::map price levels and std::list queues. v2 uses a flat level array with a bitmap, a preallocated order pool and an open-addressing id map. Both replay the same seeded stream, and their fill streams hash identically.

Two-thread pipeline: lock-free SPSC queue

A producer thread feeds the engine thread through a bounded ring buffer: acquire/release atomics, 128-byte padding (M-series cache line), batch pops.
